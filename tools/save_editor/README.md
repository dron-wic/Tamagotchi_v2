# Tamagotchi Save Editor

Python (3.10+) + tkinter, без внешних зависимостей. Читает и пишет бинарный `SaveData` v5 (`86` байт, magic `TAMA`, CRC32). Файлы v3 и v4 открываются со значениями новых полей по умолчанию и при сохранении становятся v5.

## Запуск

```bash
cd tools/save_editor
python editor_ui.py
```

## Round-trip с устройством

1. Вставь microSD в T-Display S3 Pro.
2. Настройки → **Бэкап на SD** → файл `/backup/save_<unix>.bin`.
3. На ПК открой файл в редакторе, правь, Save.
4. Верни карту в плату → Настройки → **С SD** (подтверди) — подтянется **новейший** `save_*.bin`.

Сейв игры на устройстве по-прежнему живёт в LittleFS; SD хранит только копии.
